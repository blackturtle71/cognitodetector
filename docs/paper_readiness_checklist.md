- [x] Feature model revision and artifact-producing dependencies pinned.
- [x] Participant speech concatenation and official BGE pooling implemented.
- [x] Participant-grouped repeated nested evaluation implemented.
- [x] Candidate selection and baseline comparisons confined to outer training data.
- [x] Per-seed pooled OOF metrics and participant-clustered paired bootstrap implemented.
- [x] Exact age/sex sensitivity cohort and full protocol rerun implemented.
- [x] Aggregate table and EPS/PNG figure generation implemented.
- [x] Seed-7 held-out positive-probability SHAP protocol implemented.
- [ ] Complete the full five-seed runs on the final immutable feature table.
- [ ] Inspect generated tables and figures without changing the prespecified protocol.
- [ ] Supply and revise the manuscript source.
- [ ] Confirm author list, affiliations, contributions, acknowledgements, and conflicts.
- [ ] Confirm dataset-access, consent, and ethics language with the data agreement.
- [ ] Choose a repository license and add citation metadata.
- [ ] Check the target journal's requirements immediately before submission.
